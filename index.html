📱

Dynamic QR Code Generator

Lecturers generate time-bound QR codes for individual lecture sessions, displayed in full-screen projector mode with live countdown timers.

📷

Authenticated Camera Scanner

Students scan lecture QR codes using mobile device cameras with instant verification and a six-character manual code fallback.

⏳

Automated Latecomer Detection

Attendance timestamps are compared against the permitted attendance threshold to categorize students as Present or Late.

🛡️

Duplicate Attendance Prevention

Database constraints prevent a student from registering attendance more than once for the same lecture session.

🎯 Core Project Objectives (GET 411)

  • Digitize attendance recording across university lecture halls.
  • Allow lecturers to generate unique QR codes for lecture sessions.
  • Allow authenticated students to scan QR codes using cameras.
  • Record attendance timestamps using trusted backend operations.
  • Identify students who arrive after the permitted attendance time.
  • Prevent duplicate attendance submissions using database constraints.
  • Provide attendance dashboards and downloadable CSV reports.
